## Mapeo de columnas

| CSV                     | Seed / modelo                                                      | Nota                              |
| ----------------------- | ------------------------------------------------------------------ | --------------------------------- |
| Nombre                  | SupplyItem.nombre                                                  | Nombre del insumo                 |

## Reglas recomendadas para el seed

- Crear o actualizar categorías por `(tenantId, nombre)`.
- Crear o actualizar proveedores por `(tenantId, nombre normalizado)` según la restricción existente.
- Crear o actualizar insumos por `(tenantId, codigoInterno)`.
- Crear `SupplierProduct` por `(tenantId, supplierId, supplyItemId)`.
- `factorConversion = 1`.
- `stockMinimoBodega = 0`, `stockMaximoBodega = 0`, salvo que el seed actual tenga otra convención.
- `aplicaVencimiento = false`, `aplicaLote = false`, `isActive = true`.
- Para múltiples proveedores, el primero puede quedar con `esProveedorPrincipal = true` y los demás en `false`.
