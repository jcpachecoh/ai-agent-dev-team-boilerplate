# OS-594 — Retención en la fuente (tabla progresiva Ley 2277/2022)

## Objetivo

Reemplazar el placeholder `incomeTaxWithholding = 0` del motor de liquidación mensual (OS-380) por el cálculo real de retención en la fuente sobre salarios, conforme al alcance reducido definido en `tasks/nom-04-payroll-attendance-reports/task-04-legal-hardening.md` §4.2.

## Alcance implementado

- Modelo Prisma `TaxWithholdingBracket` versionado por vigencia (`validFrom` / `validTo`).
- Seed de los 7 tramos oficiales Ley 2277/2022 (vigencia global **provisional** desde 2025-01-01).
- Resolución por fecha del período vía `TaxWithholdingBracketsService.preload()` + `TaxWithholdingBracketSnapshot.bracketsAt(date)`.
- UVT resuelta exclusivamente vía `LaborLegalParameter` key `'UVT'`.
- Motor (`PayrollCalculationService`) recibe tramos resueltos en `PayrollLegalRates.taxWithholdingBrackets` — **sin acceso a Prisma**.
- Validaciones: rangos superpuestos, más de un tramo abierto, tabla incompleta o inexistente.
- Tests de los 7 tramos, fronteras, exención, integral, export PDF/Excel.

## Fórmula — alcance reducido (task-04 §4.2)

```
ingresoBaseRetencion = contributionBase − healthDeduction − pensionDeduction
retención = (uvtIngreso × tarifa − impuestoFijoUvt) × UVT   → redondeo Math.round (COP entero)
```

### Conceptos incluidos

| Concepto                                | Tratamiento                                                    |
| --------------------------------------- | -------------------------------------------------------------- |
| Salario ORDINARIO prorrateado           | `contributionBase` = `salaryBase`                              |
| Salario INTEGRAL                        | `contributionBase` = 70% de `salaryBase` (CST art. 132 par. 2) |
| Aportes salud/pensión empleado (4% c/u) | Restados de la base antes de aplicar tabla                     |
| Tabla progresiva UVT                    | 7 tramos desde `TaxWithholdingBracket`                         |
| Valor UVT                               | `LaborLegalParameter` key `'UVT'` por vigencia                 |
| Exención                                | `EmployeeDetails.isExemptFromTax = true` → retención = 0       |

### Conceptos excluidos (no inventados)

| Concepto                                      | Motivo                            |
| --------------------------------------------- | --------------------------------- |
| Deducción por dependientes (25%, máx. 32 UVT) | Sin campo en schema               |
| AFC / medicina prepagada / otras depuraciones | No definidas en spec del proyecto |
| Auxilio de transporte en base gravable        | No definido en task-04 §4.2       |
| Horas extra en base gravable                  | No definido en task-04 §4.2       |
| Override manual `withholdingRate` (OS-559)    | Desconectado del motor automático |

## Reglas de redondeo

- **UVT ingreso:** `ingresoBaseRetencion / uvt` (sin redondeo intermedio).
- **Retención final:** `Math.round(withholdingUvt × uvt)` — peso entero COP, consistente con `roundCOP()` del motor.
- **Aportes salud/pensión:** `roundCOP(contributionBase × 4%)` antes de restar de la base.

## Resolución histórica por fecha

| Parámetro | Resolución                                                                               |
| --------- | ---------------------------------------------------------------------------------------- |
| UVT       | `LegalParameterSnapshot.numberAt('UVT', periodEndDate)`                                  |
| Tramos    | `TaxWithholdingBracketSnapshot.bracketsAt(periodEndDate)` — vigencia activa más reciente |
| Período   | Último día del mes calendario (`to` en `ReportsService.getPayrollReport`)                |

Ambos snapshots se precargan una vez por corrida de reporte (no N+1 por empleado).

## Fail-fast — configuración faltante

| Escenario                        | Comportamiento                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| UVT ausente para la fecha        | `NotFoundException` en `LegalParameterSnapshot.numberAt()` → falla `getPayrollReport` |
| Tramos ausentes para la fecha    | `NotFoundException` en `TaxWithholdingBracketSnapshot.bracketsAt()`                   |
| Tabla incompleta (< 7 tramos)    | `BadRequestException` en validación de snapshot                                       |
| UVT ≤ 0 o tramos vacíos en motor | `BadRequestException` en `PayrollCalculationService` (no retención silenciosa en 0)   |
| Empleado exento                  | Retención = 0 (válido)                                                                |
| Ingreso base ≤ 0                 | Retención = 0 (válido)                                                                |

## Desglose de retención (OS-594 — fase UI)

### Contrato API (`PayrollEmployeeRowDto.taxWithholdingBreakdown`)

| Campo                      | Tipo           | Descripción                                                |
| -------------------------- | -------------- | ---------------------------------------------------------- |
| `taxWithholdingBase`       | number         | Base gravable en COP                                       |
| `uvtValue`                 | number         | UVT en COP del período                                     |
| `taxWithholdingBaseUvt`    | number         | Base en UVT                                                |
| `bracketLowerUvtExclusive` | number \| null | Límite inferior del tramo (exclusivo). null si exento      |
| `bracketUpperUvtInclusive` | number \| null | Límite superior (inclusivo). null = tramo abierto o exento |
| `marginalRate`             | number \| null | Tarifa marginal. null si exento                            |
| `fixedTaxUvt`              | number \| null | Componente fijo en UVT. null si exento                     |
| `incomeTaxWithholding`     | number         | Retención final COP (igual a `row.incomeTaxWithholding`)   |
| `isExemptFromTax`          | boolean        | true → no se asigna tramo                                  |

**Reglas:**

- Empleado exento: retención 0, `isExemptFromTax=true`, tramo null.
- Base ≤ 95 UVT: retención 0, tramo 0% (0–95 UVT), sin tarifa gravada.
- Tramo superior abierto: `bracketUpperUvtInclusive=null`.
